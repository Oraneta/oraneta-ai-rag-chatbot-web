## Acerca del proyecto

**Oraneta AI RAG Chatbot Web** es una aplicación de inteligencia artificial que permite a las empresas crear y probar asistentes comerciales personalizados utilizando sus propios documentos.

La solución combina modelos de lenguaje, búsqueda semántica y generación aumentada por recuperación (RAG) para responder preguntas sobre productos, servicios y procesos empresariales.

El objetivo es demostrar cómo una empresa puede transformar su conocimiento en un asistente digital capaz de interactuar con clientes de forma natural.

---

## ¿Qué problema resuelve?

Las empresas almacenan información valiosa en documentos, catálogos, manuales y archivos que no siempre están disponibles para sus clientes o colaboradores.

Oraneta AI permite aprovechar esta información para:

- Automatizar respuestas a preguntas frecuentes.
- Facilitar consultas sobre productos y servicios.
- Reducir tareas repetitivas de atención comercial.
- Mejorar el acceso al conocimiento empresarial.
- Demostrar las posibilidades de los asistentes inteligentes.

---

## Funcionalidades principales

### Inteligencia artificial conversacional

Genera respuestas en lenguaje natural utilizando modelos de inteligencia artificial de OpenAI.

### Recuperación aumentada por generación (RAG)

Utiliza búsqueda semántica sobre una base de conocimiento creada a partir de la información proporcionada por el usuario.

### Procesamiento de documentos

Permite cargar archivos PDF, DOC, DOCX y TXT para construir una base de conocimiento temporal.

### Asistente comercial personalizado

Responde preguntas sobre productos y servicios utilizando la información disponible en los documentos cargados.

### Memoria conversacional

Conserva el contexto reciente de la conversación durante la sesión activa.

### Gestión de sesiones temporales

Cada demostración dispone de una sesión independiente con una duración predeterminada de 45 minutos.

### Eliminación automatizada

El sistema incorpora mecanismos para eliminar sesiones, archivos y recursos asociados al finalizar la demostración.

## Arquitectura tecnológica

La aplicación combina tecnologías de inteligencia artificial, desarrollo web, almacenamiento temporal y servicios en la nube.

| Componente | Tecnología |
|---|---|
| Inteligencia artificial | OpenAI API |
| Modelo de lenguaje | GPT, configurable |
| Arquitectura de conocimiento | RAG |
| Búsqueda semántica | OpenAI Vector Stores |
| Recuperación de información | OpenAI File Search |
| Backend | Python + Flask |
| API | REST |
| Gestión de sesiones | Redis |
| Automatización | APScheduler |
| Infraestructura | Microsoft Azure App Service |

### Flujo de funcionamiento

## Prueba la aplicación

La demostración está disponible públicamente en el sitio oficial de Oraneta.

### Acceso

**[Abrir demostración interactiva](https://oraneta.com/chatbot-para-empresas/)**

### Instrucciones

**1. Accede a la demostración**

Visita el enlace oficial de Oraneta.

**2. Acepta las condiciones**

Confirma que deseas utilizar una demostración temporal.

**3. Carga información empresarial**

Selecciona un archivo PDF, DOC, DOCX o TXT con información de productos, servicios o procesos de una empresa.

**4. Espera el procesamiento**

La aplicación crea una base de conocimiento temporal utilizando la información proporcionada.

**5. Conversa con el asistente**

Realiza preguntas relacionadas con el contenido cargado.

Ejemplos:

- ¿Qué productos ofrece esta empresa?
- ¿Cuáles son sus principales servicios?
- ¿Qué beneficios tiene este producto?
- ¿Qué opciones están disponibles?
- ¿Cómo funciona el servicio?

**6. Finaliza la demostración**

La sesión tiene una duración predeterminada de 45 minutos. El sistema incorpora procesos automáticos de eliminación de los recursos asociados.

### Consideraciones

- Utiliza documentos de prueba o información no confidencial.
- Las respuestas dependen del contenido proporcionado.
- La demostración requiere conexión a Internet.
- No es necesario instalar software para probarla desde el sitio web.
